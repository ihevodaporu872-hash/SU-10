# Проект Alpha — Жилой комплекс

## Общая информация

- **Заказчик**: ООО "Строительная компания"
- **Адрес**: г. Москва, ул. Примерная, д. 123
- **Площадь**: 45 000 м²
- **Этажность**: 25 этажей

## Основные характеристики

### Конструктивная схема
- Монолитный железобетонный каркас
- Наружные стены — газобетонные блоки
- Фасад — навесная вентилируемая система

### Инженерные системы
- Центральное отопление
- Приточно-вытяжная вентиляция
- Система кондиционирования
