## Часто используемые формулы

### Расчёт арматуры изгибаемых элементов

```
As = M / (Rs × z)

где:
  As — площадь арматуры
  M  — изгибающий момент
  Rs — расчётное сопротивление арматуры
  z  — плечо внутренней пары сил
```

### Проверка прочности по наклонным сечениям

```
Q ≤ Qb + Qsw

где:
  Q   — поперечная сила
  Qb  — усилие, воспринимаемое бетоном
  Qsw — усилие, воспринимаемое поперечной арматурой
```
