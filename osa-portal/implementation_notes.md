# Implementation Notes — OSA Portal

## Принятые технические решения

### Модуль "База знаний"
- **Чтение файлов**: Используется Node.js fs API через API Route для рекурсивного чтения .md файлов
- **Рендеринг Markdown**: react-markdown + remark-gfm для поддержки GitHub Flavored Markdown
- **Поиск**: Клиентский полнотекстовый поиск по загруженным документам (без внешних зависимостей)
- **Кэширование**: Документы загружаются один раз при монтировании компонента

### Модуль "Тендерный отдел"
- **Парсинг Excel**: Библиотека xlsx (SheetJS) для чтения .xlsx/.xls файлов
- **Генерация PDF**: jspdf + jspdf-autotable для создания табличных отчётов
- **Шрифты PDF**: Встроенные шрифты (без кириллицы в базовой версии) — для кириллицы требуется добавить кастомный шрифт
- **Маппинг видов работ**: Статический словарь соответствия работ и инженеров

### Уведомления Telegram
- **API**: Используется Telegram Bot API через fetch
- **Server Action**: Next.js Server Actions для безопасной отправки (токен не попадает на клиент)
- **Env переменные**: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID в .env.local

### Распределение по инженерам
```
Земляные работы       → Инженер 2
Монолитные работы     → Инженер 1, Инженер 2
Технология            → Инженер 2
Каменная кладка       → Инженер 2
Фасады                → Инженер 2
Монолит               → Инженер 1
```

## Известные ограничения
1. PDF-отчёты: кириллица требует подключения кастомного шрифта
2. Поиск: работает только по загруженным в память документам
3. Telegram: требует настройки бота и chat_id в .env.local
