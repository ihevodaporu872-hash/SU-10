# Implementation Notes — OSA Portal

## Принятые технические решения

### Модуль "База знаний" (RAG-прототип)
- **API Route**: `/api/knowledge` — рекурсивное чтение .md файлов из `/data-source/projects-md`
- **Рендеринг Markdown**: react-markdown + remark-gfm для поддержки GitHub Flavored Markdown
- **Поиск**: Клиентский полнотекстовый поиск по загруженным документам
- **UI**: Левая панель со списком проектов, правая — просмотр документа
- **Группировка**: Документы автоматически группируются по папкам

### Модуль "Анализ чертежей"
- **PDF Viewer**: react-pdf + pdfjs-dist для отображения PDF
- **Маркеры ошибок**: Интерактивные точки с координатами из JSON
- **Боковая панель**: Детали ошибки, кнопки Подтвердить/Отклонить
- **Фильтрация**: По ответственным инженерам (Инженер 1, 2, 5)
- **Уведомления**: При подтверждении критической ошибки → Telegram

### Модуль "Тендерный отдел"
- **Парсинг Excel**: Библиотека xlsx (SheetJS) для чтения .xlsx/.xls файлов
- **Авто-маппинг**: Виды работ автоматически сопоставляются с инженерами
- **Чек-листы**: Чекбокс "Проверено" + пометка "Критическая"
- **Value Engineering**: Текстовое поле для предложений по оптимизации
- **Генерация PDF**: jspdf + jspdf-autotable для отчётов
- **Уведомления**: При пометке критической позиции → Telegram

### Уведомления Telegram
- **API Route**: `/api/notify` — POST для отправки, GET для проверки статуса
- **Server Actions**: `lib/notifications.ts` — безопасная отправка (токен на сервере)
- **Env переменные**:
  - `TELEGRAM_BOT_TOKEN` — токен бота
  - `TELEGRAM_CHAT_ID` — ID чата для уведомлений
- **Триггеры**:
  - Подтверждение критической ошибки в "Анализ чертежей"
  - Пометка критической позиции в "Тендеры"

### Логика распределения по инженерам
```
Вид работ                    → Ответственный
─────────────────────────────────────────────
Земляные работы              → Инженер 2
Монолитные работы            → Инженер 1, Инженер 2
Технология                   → Инженер 2
Каменная кладка              → Инженер 2
Фасады                       → Инженер 2
Монолит (бетон, арматура)    → Инженер 1
Электромонтажные работы      → Инженер 2
Сантехнические работы        → Инженер 5
```

## Известные ограничения

1. **PDF-отчёты**: Базовые шрифты jsPDF не поддерживают кириллицу. Для корректного отображения русского текста требуется подключение кастомного шрифта (PTSans, Roboto и т.д.)

2. **Поиск в базе знаний**: Работает только по загруженным в память документам. Для больших объёмов данных рекомендуется интеграция с векторной БД (Pinecone, Weaviate)

3. **Telegram уведомления**: Требуют создания бота через @BotFather и добавления токена в `.env.local`

4. **PDF Viewer**: Worker загружается с unpkg.com CDN. Для offline-режима требуется локальная копия

## Настройка Telegram бота

1. Откройте @BotFather в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте токен в `TELEGRAM_BOT_TOKEN`
4. Добавьте бота в чат и получите `TELEGRAM_CHAT_ID` через:
   ```
   https://api.telegram.org/bot<TOKEN>/getUpdates
   ```
5. Перезапустите приложение
